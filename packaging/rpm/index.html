Weather: signed RPM repository

Packages and repository metadata are signed with the key below. Source and documentation: github.com/wtp128pro/weather.

Install (Fedora 44, x86_64, dnf5)

sudo curl -fsSLo /etc/yum.repos.d/weather.repo https://wtp128pro.github.io/weather/weather.repo
sudo dnf install weather

dnf asks you to confirm the key fingerprint on first use. Compare it with the one below.

Signing key

Weather Release Signing Key <wtp128pro@users.noreply.github.com>
RSA 4096, created 2026-10-11, expires 2029-10-10
Fingerprint: 6C3D CB7D 86FE 6795 DC72  5E97 FC6A DF53 F5A8 E21F

RPM-GPG-KEY-weather (ASCII-armored public key). The fingerprint is also in the README.

Verify a downloaded RPM by hand

sudo rpm --import https://wtp128pro.github.io/weather/RPM-GPG-KEY-weather
rpm -K weather-*.rpm        # must print: digests signatures OK

A package without a signature also exits 0 and prints only digests OK; look for signatures OK.
