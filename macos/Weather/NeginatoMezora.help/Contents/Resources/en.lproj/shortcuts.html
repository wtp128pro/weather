Keyboard Shortcuts & Menus

Shortcuts

ShortcutCommand
⌘NFile › Add a City… (opens the Add a city window)
⌘RView › Refresh (the selected place)
⌘UView › Switch Selected Place to Celsius / Fahrenheit: switches the selected place between °F and °C (with no place selected, Set Default Units to Celsius / Fahrenheit switches the default units for new places)
⌃⌘SView › Show/Hide Sidebar
⌘,Neginato Mezora › Settings… (opens on the Sources tab)
⌘? (⇧⌘/)Help › Neginato Mezora Help
⌘QQuit (pending changes are saved first)
↑ ↓Select the previous or next place in the sidebar
EscClose the Add a city window
Return / SpaceIn the Add a city window: add the highlighted result

Menus

  • Neginato Mezora: About Neginato Mezora; Settings… (⌘,, Sources tab); Data Sources & Weights… (the Weights tab); Stations & Keys… (the Stations tab); Quit.
  • File: Add a City… (⌘N).
  • View: Refresh (⌘R); Switch Selected Place to Celsius or Fahrenheit (⌘U; with no place selected, Set Default Units to Celsius or Fahrenheit); Show/Hide Sidebar.
  • Help: Neginato Mezora Help (⌘?), then direct links to Reading the Forecast, the Rain Graph & Bars Guide, Data Sources & Blend Weights, Station Settings, Free Keys for More Stations, Live Station Observations, Learned Local Corrections, Forecast Algorithms & Citations, and Troubleshooting & FAQ.

Toolbar

ButtonWhat it does
+Add a city (⌘N).
RefreshRefresh this place (⌘R); dimmed while it loads or when offline.
°F / °CShows the selected place's unit; click to switch that place (with no place selected, the default units for new places). Its tooltip is the ⌘U title: Switch Selected Place to Celsius (or to Fahrenheit), or with no place selected Set Default Units to Celsius (or to Fahrenheit).
GearSettings (⌘,).

Each sidebar row's … button holds Name / Edit Location…, Set Location Name, Move up, Move down and Remove (also available to VoiceOver as row actions). Rows have no right-click menu.
