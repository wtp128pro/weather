Privacy, Data & Storage

Neginato Mezora has no account, no analytics and no server of its own. It talks directly to public weather services. This page lists what it sends and what it stores.

Requests identify the app by name in their User-Agent; no personal identifier is sent. Turning a forecast source off in Settings › Sources stops its forecast requests; station networks have their own switches in Settings › Stations.

What is stored on this Mac

The app is sandboxed. Its files are in ~/Library/Containers/io.github.wtp128pro.Weather/Data/Library/:

FileContents
Application Support/weather/places.jsonYour places, names, order and units
Application Support/weather/settings.jsonDefault units for new places, sources turned off, the selected place
Application Support/weather/weights.jsonYour weight multipliers
Application Support/weather/station-settings.jsonCorrections on or off, station networks turned off
Application Support/weather/local-bias.jsonThe learned local corrections
Application Support/weather/stations.jsonThe stations seen, their latest readings and track records
Caches/weather/forecasts.jsonThe last forecast of each place, shown at launch and offline

API keys for the station networks are stored in your login Keychain (as "Neginato Mezora: … key"), never in these files, and are sent only to their own service over HTTPS. Remove one in Settings › Stations, or in the Keychain Access app.

To start completely fresh, quit the app and delete the folder above (and the keys in Keychain Access).
